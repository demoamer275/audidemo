# cards-teaser

Custom **cards** block. Purpose: Bild-oben-Teaser mit Titel, Text, Textlink und Verbrauchsangaben im 3-spaltigen Raster.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: image (with alt); cell 2: heading, body paragraph(s), CTA link; cell 3: consumption/emission disclaimer (rich text).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
