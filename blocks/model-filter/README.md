# model-filter

Custom **model-filter** block. Purpose: Statische Filterleiste des Modellfinders: beschriftete Gruppen von Pill-Buttons (Antriebstyp, Modelle, Fahrzeugtyp) und eine Linkzeile.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: group item: cell 1 label (text), cell 2 buttons (richtext ul, one li per pill); links item: one richtext cell with plain links.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
