# cards-stats

Custom **cards** block. Purpose: Kennzahlen-Kacheln ohne Bild (Dachzeile, große Zahl, Einheit, Beschreibung).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: eyebrow; cell 2: value; cell 3: unit; cell 4: caption (all plain text).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
