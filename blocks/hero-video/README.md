# hero-video

Custom **hero** block. Purpose: Vollflächige Bühne mit Hintergrundvideo, H1, Preis, CTAs und Verbrauchsangaben.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: video link (MP4 in DAM, e.g. /content/dam/audidemo/<file>.mp4); row 2: poster image (with alt); row 3: H1 title, price paragraph, CTA links; row 4: consumption/emission disclaimer (rich text).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
