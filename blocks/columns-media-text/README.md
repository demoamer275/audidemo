# columns-media-text

Custom **columns** block. Purpose: Großes Bild neben Textspalte mit Überschrift, Text, Liste und Button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image (with alt) | heading, paragraph, bullet list, button link. Authored as one row with two cells (image | text) or, in Universal Editor, as an image field plus a text group (title, rich text body, link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
