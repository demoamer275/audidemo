# cards-carline

Custom **cards** block. Purpose: Modellreihen-Kacheln: Fahrzeugbild, Titel, Modellanzahl als Link zur Modellreihen-Seite.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: image (+ alt); cell 2: richtext h2 title + paragraph with count link; cell 3: electric boolean.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
