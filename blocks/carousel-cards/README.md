# carousel-cards

Custom **carousel** block. Purpose: Horizontaler Slider mit Bild- oder Video-Karten, Titel und Text.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: image (with alt, optional); cell 2: video link (MP4 in DAM, optional, replaces image); cell 3: title (h3) + text.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
