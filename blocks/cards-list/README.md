# cards-list

Custom **cards** block. Purpose: Vertical list of teasers linking to detail pages (related articles, press kits): image, date and category, linked H3 title, optional description.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per list item. cell 1: image (+ alt); cell 2: richtext with meta paragraph ('03/02/2026 · Models'), heading (h3) linked to the detail page, optional description paragraph. Every part optional..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
