# columns-panels

Custom **columns** block. Purpose: Fixed pair of different content panels side by side, e.g. media contact and customer-service teaser.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row x 2 columns. Each column: heading (h3), optional portrait image, text (name link, role, tel: and mailto: links or a paragraph), trailing link/button. In Universal Editor each column holds title, image, text and button components..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
